# Negotiation intelligence

ConveyMate now includes a mandatory `negotiationIntelligence` section in every newly generated report. The worker runs a dedicated specialist pass after core analysis normalisation and before final summary compilation. The section converts evidence-backed findings into practical, buyer-friendly negotiation levers, includes confidence and impact signals, and lists next steps for conveyancer discussion. If no strong levers are identified, the section is still generated with a clear fallback message and focused follow-up actions.
